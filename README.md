# 🚀 Personal Portfolio - Muhammad Fathan Agniyan

Sebuah website portofolio modern, responsif, dan interaktif yang dibangun dengan tema **DevOps & Cloud Engineering**. Proyek ini dirancang menggunakan HTML, CSS, dan Vanilla JavaScript murni tanpa framework eksternal, menonjolkan antarmuka yang bersih (*clean UI*), elemen *glassmorphism*, dan transisi yang mulus.

## ✨ Fitur Utama

- **🌓 Dark/Light Mode:** Tema yang dapat disesuaikan (terang/gelap) dan terintegrasi dengan `localStorage` untuk menyimpan preferensi pengguna lintas sesi.
- **⏳ Custom Preloader:** Layar pemuatan dinamis dan sinematik yang warna latar serta teksnya otomatis beradaptasi dengan mode tema yang aktif.
- **⌨️ Typewriter Effect:** Animasi mengetik dinamis pada *hero section* untuk menampilkan peran dan fokus keahlian profesional secara interaktif.
- **📱 Responsive UI & Navigation:** 
  - **Desktop:** Navbar bergaya *floating pill* yang mengecil dan melayang mulus saat halaman digulir.
  - **Mobile:** Menu navigasi berbentuk *glassmorphism card drawer* yang elegan dan tidak memakan seluruh layar.
- **🕸️ Tech-Themed Background:** Latar belakang *grid* minimalis dengan efek *glow* pendar cahaya yang beradaptasi dengan mode gelap dan terang.
- **📌 Optimized Layout:** Penggunaan *sticky positioning* pada bagian pengalaman kerja untuk menyeimbangkan ruang kosong (*white space*) dengan riwayat akademik.

## 🛠️ Teknologi yang Digunakan

- **HTML5:** Struktur semantik dan aksesibilitas.
- **CSS3:** Variabel CSS (*Design Tokens*), Flexbox, CSS Grid, Pseudo-elements (`::before`), serta Animasi & Transisi kustom.
- **JavaScript (Vanilla):** Manipulasi DOM, penanganan *event listener*, *theme toggle logic*, *timeout* untuk preloader, dan rekursi logika *typewriter*.
